# GlobalImpact - Next.js UI/UX Hackathon 🌍

![Next.js](https://img.shields.io/badge/Next.js-15-black?style=for-the-badge&logo=next.js)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-black?style=for-the-badge&logo=framer)

A modern, minimalistic website template designed for international nonprofits, built for the **Next.js UI/UX Hackathon**. 

This project focuses on providing a seamless donation experience, easy program discovery, and a clean, mobile-first interface that builds trust and drives social impact.

## ✨ Features

- **Seamless Donation Flow**: A state-driven, multi-step donation form that offers a frictionless user experience.
- **Program Discovery**: Dynamic search and category filtering to help users find initiatives they care about.
- **Premium UI/UX**: Clean typography, trust-inspiring color palettes (Emerald/White), and high-quality micro-animations powered by Framer Motion.
- **Mobile-First Design**: Fully responsive across all device sizes.
- **Financial Transparency**: Dedicated sections showcasing the organization's impact and financial breakdown.

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 💻 Running Locally

To run this project on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/saisaran-m/global-impact-hackathon.git
   ```
2. Navigate into the directory:
   ```bash
   cd global-impact-hackathon
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
